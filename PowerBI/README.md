This folder contains the Power BI dashboard file for Employee Attrition Analysis.

File Included:-
- HR Analysis Dashboard.pbix

Dashboard Features:
- KPI Cards
- Department-wise Attrition Analysis
- Salary Analysis
- Job Satisfaction Analysis
- Work-Life Balance Analysis
- Exit Reason Analysis
- Interactive Filters and Slicers

The dashboard provides insights into employee attrition patterns and helps identify key factors affecting employee turnover.
