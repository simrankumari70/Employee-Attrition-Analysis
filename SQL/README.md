# SQL Analysis

This folder contains SQL queries used for employee attrition analysis.

File Included:
- Employee_Attrition_Analysis.sql

Analysis Performed:
- Total Employee Count
- Attrition Count
- Attrition Rate Calculation
- Department-wise Attrition Analysis
- Salary-wise Attrition Analysis
- Job Satisfaction Analysis
- Work-Life Balance Analysis
- Promotion Analysis
- Exit Reason Analysis

SQL was used to explore the dataset and identify factors contributing to employee turnover.
