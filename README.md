# Employee Attrition Analysis Dashboard

## Project Overview

This project analyzes employee attrition patterns, reasons and identifies factors affecting employee turnover.

## Tools Used

- SQL
- Excel
- Power Query
- Power BI

## Project Workflow

1. Data Cleaning using Excel and Power Query
2. Data Analysis using SQL
3. Exploratory Analysis using Pivot Tables
4. Dashboard Development in Power BI
5. Insights and Recommendations

## Key Insights

- Attrition Rate: 17.95%
- HR department has the highest attrition(681).
- Medium salary employees leave the most(841).
- Poor work-life balance is linked to higher attrition(731).
- Lower job satisfaction increases attrition(729).
- Exit reasons are almost equally distributed(nearest 20%).

## Recommendations

- Improve work-life balance.
- Enhance employee engagement.
- Review compensation policies.
- Strengthen retention programs in HR.
- Improve career growth opportunities.
